# Hệ Thống Ôn Luyện Thi Sát Hạch Trực Tuyến - NMTĐ Đồng Nai 5

Cổng ôn luyện thi trắc nghiệm chức danh Trưởng ca, Trưởng kíp, Điều hành viên và Sửa chữa năm 2025.

## Cấu trúc thư mục
- index.html: Giao diện thi trắc nghiệm tinh gọn (chạy trực tiếp trên GitHub Pages).
- data/truong_ca.json: Ngân hàng 246 câu hỏi Trưởng ca (đã mã hóa băm đáp án chống lộ).
- data/truong_kip_dhv.json: Ngân hàng 185 câu hỏi Trưởng kíp, ĐHV, Sửa chữa (đã mã hóa băm đáp án chống lộ).

## Hướng dẫn bật GitHub Pages
1. Tạo Repository mới trên GitHub.
2. Upload toàn bộ thư mục này lên.
3. Vào **Settings** -> **Pages** -> Chọn Branch main (hoặc master) / 
oot -> Bấm **Save**.
4. Chờ khoảng 1-2 phút là có đường link web cho toàn thể anh em truy cập ôn luyện!
